# 설정집 — 개인용 웹소설 작업실

캐릭터·작품설정 위키, 회차별 원고 편집기, 타임라인·플롯·관계도·지도를 한곳에서 관리하는 **서버 없는 정적 웹앱**입니다.
모든 데이터는 **이 브라우저(IndexedDB)에만** 저장되고, GitHub에는 앱 코드만 올라갑니다.

## GitHub Pages로 배포하기

1. GitHub에서 새 저장소를 만듭니다. (이름은 남이 짐작하기 어려운 것으로, 예: `x7-notebook`)
2. 이 폴더의 **모든 파일**(`index.html`, `js/`, `css/`, `icons/` 등)을 저장소 루트에 올립니다.
3. 저장소 **Settings → Pages → Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 에서 열립니다. 이 주소를 즐겨찾기/홈 화면에 추가하세요.

### 비공개로 쓰기 위한 주의
- 주소를 공개하지 않아도, **주소를 아는 사람은 누구나 열 수 있어요.** 다만 글·설정은 저장소가 아니라 각자 브라우저에 있으므로, 남이 열어도 빈 앱만 보입니다.
- **백업 파일(zip/json)을 저장소에 올리지 마세요.** 올리는 순간 공개됩니다.
- `robots.txt`와 `noindex` 설정이 들어 있어 검색엔진에는 잡히지 않게 해 두었습니다.
- 저장소를 비공개(private)로 두고 Pages를 쓰려면 GitHub 유료 플랜이 필요합니다. 코드까지 숨기고 싶을 때만 고려하세요.

## 데이터 보관 (중요)
- 브라우저 방문 기록/사이트 데이터를 지우면 작품 데이터도 사라집니다.
- **설정 → 백업 / 복원**에서 `전체 백업(.zip)`을 주기적으로 받아 두세요. (글·설정·이미지 모두 포함)
- 다른 기기에서 쓰려면 백업 파일을 옮겨 `백업 불러오기`로 복원합니다.
- 사용자 사이트 주소(도메인)가 바뀌면 저장 공간도 달라져서 데이터가 보이지 않습니다. 이때도 백업으로 옮기면 됩니다.

## 업데이트 배포
코드를 바꿔 다시 올릴 때 `js/db.js`의 `APP_VERSION`과 `version.json`의 `version`을 같은 값으로 올리면, 앱을 열 때 "새 버전" 안내가 떠요. `version.json`의 `notices`에 공지를 적으면 설정 화면에 표시됩니다.

## 주요 기능
- 위키: 캐릭터/작품설정 문서, 정보 상자(이미지 여러 장), 목차·하위 목차(접기), 글/이미지/표/스테이터스/빈 줄 블록, 각주 `((내용))`, 문서 연결 `[[이름]]`, 템플릿, 분류·태그
- 소설: 회차·폴더·외전, 서식 편집(글꼴·크기·줄간격·정렬·들여쓰기·이미지·각주·문서 링크), 집중 모드, 모바일 미리보기, 게시글 보기, 자동 저장
  - 불러오기: txt(UTF-8/CP949), docx, hwpx · 내보내기: txt, docx, epub, pdf(인쇄), 클립보드 복사
- 아카이브: 타임라인(세로/가로, 분류·캐릭터별 표), 플롯(폴더형/흐름형, 선 연결), 관계도·조직도(PNG 저장), 지도 생성(핀·이미지·PNG 저장)
- 앱: 4가지 테마, 글꼴/크기, PIN 화면 잠금, 화면 분할(최대 3개), 전체 검색(Ctrl+K), 앱 설치(PWA), 투고 관리, 메모, 캐릭터 통계
